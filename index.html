COASTER EVALS

LLMs design roller coasters. RollerCoaster Tycoon 2's real physics engine builds, tests, and rates them.

How the harness works

Each round a model submits a track program: a ride type, a start tile, and an ordered list of track pieces. The harness executes it inside the game via the same validated action path a human player uses, runs the simulation for ~10 game-minutes, then feeds the eval report and a screenshot back to the model for the next round.

 model (tool_use)          openrct2-cli eval               feedback
+------------------+     +----------------------+     +------------------+
| JSON track       | --> | build piece by piece | --> | ratings report   |
| program          |     | test with real train | --> | park screenshot  |
| (pieces, chain)  |     | rate the ride        |     | -> next round    |
+------------------+     +----------------------+     +------------------+

Excitement is the score. Intensity above 10 tanks it; crashes disqualify. The game engine is the judge, no LLM grading anywhere.
