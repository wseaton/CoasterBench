How the harness works

Each round a model submits a track program (start tile, heading, piece list). Real OpenRCT2 builds it, tests it, and hands back ratings plus a screenshot for the next round. Excitement is the score.

the whole loop
flowchart LR M["model
track program"] --> B["build + validate"] B --> T["test train"] T --> R["ratings + screenshot"] R --> M B -. rejected piece .-> M

Pieces go in through the same validated action path a player clicks, so an impossible curve or an open circuit fails exactly as it would in the game. Intensity over 10 tanks the ride, crashes disqualify it, and copies of stock designs scale toward zero. The engine judges, not an LLM.
